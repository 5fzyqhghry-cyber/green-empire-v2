# Зелёная Империя — Telegram Mini App

Фермерский симулятор на Phaser 3 + TypeScript + Vite.

## Деплой на Amvera

1. Создай проект в Amvera, привяжи этот GitHub-репозиторий.
2. В корне уже есть Dockerfile + amvera.yaml.
3. После сборки включи бесплатный HTTPS-домен.
4. Вставь ссылку в BotFather как Mini App URL.

Локально: `npm install` → `npm run dev`
